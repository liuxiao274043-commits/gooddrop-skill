# 质量门禁与手工修复经验

## 自动管线硬门禁

必须检查 `quality-report.json` 及 request 指定的证据。以下任一未解决都不能交付：

- `unowned_raster_text`：背景或图片层仍有应当可编辑的文字。
- `background_text_residual`：去字后留有字形、描边、阴影或空洞。
- `unexplained_visual_residual`：显著像素没有活动组件 owner；查看 `unexplained-mask.png`。
- ownership 冲突：父子或重复候选同时渲染同一像素。
- isolation 缺损：图标、线条或色块被截断，或沿文字出现透明孔洞。
- reconstructed 与 source 的显著错位、重影、漏元素或颜色错误。
- PPTX 无法 reopen，或输出对象越界/溢出。

最多进行有限的真实修复轮次；连续两轮没有可见改善即可提前切换手工重建，不为了耗尽轮数重复同一动作。

## 手工重建检查顺序

1. 生成 PPTX，同时导出同尺寸 PNG 与 layout/inspect 信息。
2. 查看整页渲染，先核对对象数量和信息层级，再核对间距与视觉细节。
3. 运行 `slides_test.py output.pptx`，要求 `Test passed. No overflow detected.`。
4. 检查 inspect：不应残留临时 Unicode 图标、占位文本或整页背景截图；图像数量应与 logo、允许整图区域和 SVG 实例数量相符。
5. 重新打开 PPTX，确认文本、形状和 SVG 未在导出时丢失。

## 过去几轮中有效的调整经验

- 自动拆分卡住时，几何规则的信息图手工重建通常更快、更稳定；保留自动诊断只用于定位失败，不要继续盲目下载或重试。
- 先用统一坐标系和数据数组搭出所有重复行/卡片，再微调局部，避免逐个手摆造成漂移。
- 文字准确性比字体完全一致更重要；先解决错字、漏字、换行和遮挡，再校字体。
- 原生右箭头、Unicode 符号常与原图图标体系不一致。严格还原时应换成 SVG，而不是继续调整字符字体。
- SVG 在 PPT 中应保持适当留白；同一图标在窄卡片中统一宽高和视觉中心，不能只按 viewBox 数字居中。
- 深色底上的单色 SVG 可在插入前替换主题色为白色，但只替换明确的主题色值，避免破坏多色图标。
- 交付新文件，保留上一版便于回退；每次修订后的预览文件使用新名称，避免误看缓存。

## 手工模式仍可保留为图片的内容

只有用户明确指定、内容本身是照片/热力矩阵/复杂纹理，或拆分不会增加实际编辑价值的区域可以作为单张图片。应裁切到内容边界，不包含周围可编辑文字和边框。

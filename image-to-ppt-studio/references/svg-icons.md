# SVG 图标去重、重绘与替换

## 识别唯一图标

先建立“出现位置 → 语义图标”的映射。按语义、轮廓拓扑和内部结构去重，不按尺寸、颜色或背景圆形的细微差异误判为新图标。常见可复用族包括：文档、搜索、电脑勾选、文件夹、盾牌、团队、工具、链路、仪表、说明、筛选、目标和方向箭头。

背景圆、卡片或底色通常由 PPT 原生形状绘制，不必烘焙进每个 SVG；若图标与背景构成不可分割的视觉标记（例如深色圆内白色漏斗），可作为一个 SVG。

## 重绘规则

- 每个唯一图标只创建一个 SVG 文件，使用稳定的 `viewBox`，透明背景，路径闭合，线帽/连接样式统一。
- 按原图重绘线条粗细、端点、留白和负空间；不要用“看起来类似”的 Unicode 字符替代。
- 主题色集中使用一个明确色值，便于插入深色区域时定向 recolor。
- 用 XML 解析器验证每个 SVG；必要时单独栅格化预览，检查断线、填充反转和裁边。
- 文件名采用有序、语义化命名，例如 `01-filter.svg`、`02-document.svg`。

## 放入 PPT

使用 artifact-tool 原生 SVG 插入：

```javascript
const svg = await fs.readFile(iconPath, "utf8");
slide.images.add({
  svg,
  alt: "Document activity icon",
  position: { left, top, width, height }
});
```

重复实例继续使用同一 `svg` 字符串。深色底白色版本可以在插入前对唯一主题色执行精确替换：

```javascript
const whiteSvg = svg.replaceAll("#00545A", "#FFFFFF");
```

替换 PPT 中临时图标时，删除原字符文本框或原生近似图形，但保留其周围卡片、圆形底和布局。给每个实例稳定名称与 alt 文本，便于 inspect 和后续批量修改。

## 替换后的验证

- 渲染整页确认所有图标语义、方向和位置与原图一致。
- 搜索 inspect/源代码，确保 `▤`、`♣`、`⚒`、`∞`、`◔`、`✎` 等临时字符已完全移除。
- 核对实例数量：唯一 SVG 文件数可以小于 PPT 图标实例数；重复出现是正确复用，不是重复绘制文件。
- 检查图标未越界、未变形，白色图标在深色底上有足够对比度。

# Image to PPT Studio

把输入视觉稿一次性处理为可交付 PPTX。优先使用自动语义拆分；若依赖不可用、连续修复无改善或严格质量门禁仍失败，直接手工重建，无需再次询问是否切换。不得用整页截图冒充可编辑结果。

## 执行入口

1. 读取 `image-to-ppt` 与 `presentations:Presentations` 的 `SKILL.md`，遵循其运行时、编辑和导出要求。
2. 查看每张源图，确认画布、层级、重复结构、文字、表格/图表、图标族和允许保留为整图的区域。用户明确指定“不用拆”的区域必须原样作为单个图片对象。
3. 按 [工具与调用](references/tools-and-prompts.md) 选择自动管线或手工重建。
4. 执行 [质量门禁与修复](references/quality-gates.md)。自动管线失败时，保留诊断证据并切换手工重建；不要继续无改善的重复修复。
5. 图标不够准确或源图包含一致的线性图标系统时，执行 [SVG 去重与替换](references/svg-icons.md)。
6. 输出新文件，不覆盖用户原文件；最终只交付通过门禁的 PPTX，并简要说明哪些区域仍是单张图片。

## 不可破坏的结果约束

- 可靠 OCR 文字必须是可编辑文本框，且只出现一次；背景或视觉组件中不得残留同一文字像素。
- 可用原生形状表达的边框、卡片、色块、分隔线、箭头和表格应使用原生对象；复杂图标优先 SVG。
- 每个独立对象在单独移动后，自身和周围对象仍应完整。语义相关不等于必须合并。
- 重复图标只绘制一个唯一 SVG 文件，但在 PPT 中按原图出现次数放置多个实例。
- 不擅自改写内容。辨识不确定的文字要对照源图核验；无法可靠确认时明确标记，不要猜。
- 手工重建也必须经过渲染、目视对比、越界/溢出检查和 PPTX reopen 检查。

## 模式选择

- **自动拆分**：模型和 OCR 已就绪，页面含照片、复杂纹理或大量不规则对象时优先。
- **直接手工重建**：信息图、论文汇报页、规则表格、卡片流、导航栏等几何结构清晰的页面，或自动管线依赖缺失且安装成本高时可直接采用。
- **自动转手工**：质量报告仍有文字残影、重复像素、所有权冲突、显著残差、组件缺损，或修复轮次无改善时立即切换。

安装 OCR、模型或大型依赖仍需用户授权；授权自动转手工不等于授权下载。
